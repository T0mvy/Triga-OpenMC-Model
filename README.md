# TRIGA-OpenMC-Model
An OpenMC implementation of a dimensions-based TRIGA reactor model. This is an independent educational model of a TRIGA-based research reactor, developed from publicly avaiable technical information.

# Status
🚧 Work in progress

This project is currently under development.


# About

This project aims to develop a simplified computational model of a research reactor based on the general characteristics of TRIGA reactor designs.

The model is intended as an educational resource for students interested in:

- Monte Carlo neutron transport
- Reactor physics
- Nuclear engineering
- Computational physics
- OpenMC

The project is designed to allow students and researches to explore reactor-physics concepts through a modifiable OpenMC model.

# Limitations

This project is an independent educational model.

It is not:

- an official model of a TRIGA reactor facility;
- an operational model;
- a reactor safety analysis;
- a licensing model;
- a substitute for experimentally validated reactor calculations.

Results should therefore be interpreted within the assumptions and limitations documented in this repository.
